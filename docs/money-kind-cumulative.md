# 入出金の絞り込み・未消込累計（1.2.44候補）

最新 main 1.2.43（01563e5）から独立した表示改善。金融記録・実績・履歴・保存・同期・認証・共有権限は変更しない。

## 表示の意味

- 「入出金」で両方／入金のみ／出金のみを選ぶ。一覧、予定日不明の別枠、月内合計、累計に適用する。初期値は両方。既存設定を移行せず、再表示時は今月・未消込・両方に戻る。
- 月内合計は選択した予定月と消込状態に合う一覧の予定額。予定日順、請求対象月の詳細表示、短い1行操作と44px操作領域は保持する。
- 未消込累計は、予定日が選択月末以前で `done !== true` の記録の予定額。前月以前を含み、翌月以降は除外。消込状態の一覧選択を変更しても累計は未消込だけとする。月を空欄にした場合は未来分も含む全期間。
- 入金・出金は別々に表示し、差引しない。部分実績も差し引かないため、銀行残高や残債の推計ではない。画面にも「予定額」「実績の差引なし」と明記する。
- 金額不明は0円とみなさず、判明額と未確認件数を併記する。0円は判明額。安全な整数範囲を超えた合計は丸めず「計算上限超過」。
- 予定日不明は月内合計・累計から除き、既存の別枠に残す。累計外の未消込件数を表示する。区分・履歴未確認は金額に含めず別件数にする。区分を選択した場合、区分不明の記録はその区分には割り当てない。

## 合成検証

Node全207件成功。予定月と対象月の違い、月跨ぎ・年跨ぎ・閏日、金額不明・0円・上限超過、済／未／全、区分切替、凍結入力の不変性を確認。

ブラウザでは11月内の入金100円に対し、10月以前を含む未消込入金1,099円と表示する例を検証。部分実績を減算しないこと、入出金別の表示、予定日不明と履歴未確認の除外、保存データ・履歴・localStorage不変、再読込時の初期表示を確認。280/320/360/390/822pxで横スクロールなし、操作文字1行・44px以上を検証し、合成画像を目視した。

関連ブラウザ回帰：money-list、money-card、money-sync、combined-sync、completion-reconcile、completion、deadline、google-account、calendar-navigation、diary-repair、diary-local-repair。日記試験の表示版番号だけを1.2.44に更新した。既存日記修復ロジックは変更していない。

未改変1.2.43からの更新は、同一originの旧タブをすべて通常終了してオンラインで開き直す条件で、通常／2.2秒遅延とも新controller・キャッシュ・オンライン／オフライン再表示・合成記録と履歴保持を確認。旧タブを開いたままの自動更新成功とは扱わない。旧1.2.43 bundleの不変性、48モジュールからのbundle生成一致、index/worker/cache版一致も検証する。
