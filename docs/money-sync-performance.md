# お金の通信まとめ処理（1.2.51候補・未公開）

AI連絡箱279番のA/Bのみ。四段階の履歴読取り、照合表示の全件読取りと読戻し、最終確認、所有者・非共有・形式・同時編集・隔離チェックを維持。照合表示の置換や最新分限定、実績や銀行の判定変更は行わない。

- RAW追記は最大500行、JSON UTF-8本文は100万バイト以下。行は分割せず順序を保つ。全行の容量を先に検証し、1行超過ならその追記は開始しない。各まとまりは順番に送る。
- ページは1000行。ヘッダー検査、空セル行の扱い、100000行上限での安全停止を維持。ちょうどページ上限なら次ページも確認する。
- 非共有確認・タブ確認・設定読取りを並行化。すべて成功した後だけ履歴・比較を並行読取りする。どれかの失敗時も全通信の終了を待つため、前の読取りが残った状態で再同期を始めない。
- 通信断で保存結果が不明なら従来どおり固定IDを読戻し、未送信分だけ再送する。大きなPOSTの分だけ結果不明の行数は増えるが、照合と重複防止は変えない。自動リトライや排他の保証は追加しない。
