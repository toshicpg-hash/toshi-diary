# 完了表示を維持してGoogleとそろえる（1.2.41候補）

1.2.40には、過去の端末履歴を守って完了表示にしたGoogle作業を、完了のまま反映する入口がなかった。左の✓は `done = !item.done` により未完了に戻す操作だった。これは実装と再現テストの不足であり、利用者の操作ミスではない。

報告された状態を合成再現した：端末の過去履歴は完了true、実施日と完了日時は空欄、現在のGoogleはprivate false、件名には✅。この場合はcompletionConflictと件名/保存情報不一致の両警告が表示される。

## 追加する操作

Google由来で端末表示が完了のToDo/タスクに「完了状態をGoogleとそろえる」を追加する。Google未確認の行では従来の完了操作と同じく無効にする。完了状態を反転せずtrueを指定し、既存の1画面で対象・Google状態・実施日を確認して「この1件を完了のまま反映」で確定する。左の✓による明示的な完了取消と、○による通常完了はそのまま維持する。

件名✅だけで自動補正しない。既存のinspect、ETag、If-Match、原文履歴保存、PATCH、Google/端末読み戻しを使用する。Googleが既に一致すればPATCHは不要。成功後は一覧の両警告が消えることを検証した。

既存実施日は表示して保持し、この整合化操作では変更しない。未記録なら空欄で入力可能。端末とGoogleの既存実施日が異なる場合や不正な日付では書き込まない。完了日時も既存値を保持し、未記録なら空欄のままにする。通常の完了操作の時刻記録は変更しない。今回の日付・個人名・金額はコードに入れていない。

照合成功後は端末専用の古い `completionCorrection` 表示も解除し、旧編集を履歴に保持する。無関係な編集・overlayフィールド、未完了の別行は保持する。認証権限・同期機構・金融記録は変更しない。
