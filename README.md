# TOSHI 日記

個人データをソースに含めない日記専用の静的画面です。

- 日記と編集履歴はブラウザの既存 IndexedDB `toshi_diary_v1` に保存します。
- 既存データがある端末では、初回の書き込み前に読み取り専用バックアップを保存し、保存したファイルの内容を端末内で照合します。
- Google同期先は利用者が指定する非公開スプレッドシートです。台帳IDや本文をこのリポジトリへ保存しません。
- 既存の編集履歴を上書きせず、追記して同期します。
- この画面は予定・資金繰り・領収書を扱いません。
- サービスワーカーは登録しません。他の画面のキャッシュやブラウザデータを削除しません。
- `config.js` は公開用のブラウザOAuthクライアントIDだけを含みます。秘密鍵やトークンは含めません。

既存のHUBと同じオリジン・同じブラウザで利用する前提です。別のブラウザや端末に保存された日記は、同じ非公開台帳を設定して同期してください。Google認証の許可状況はアカウント側の設定によって異なります。
